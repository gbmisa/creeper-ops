**Phase 1: static targets (melee raiders).**
1. **Commit.** A raider that has a live target keeps it. It lets go only when the target is dead, has left the ground (`_grounded`), is no longer walkable-to after a terrain or gate change (re-check on `RaiderField.invalidate`, not per frame), or (guards) is past `NEST_LEASH`. No timed re-pick while it holds a live target; the staggered `RAIDER_ACQUIRE_*` scan runs only for raiders with no target. A nearer target appearing does not change its mind.
2. **One path per target.** When it takes a target, test the straight segment once: walk the grid cells on the line and require `RaiderField.step_ok` for every cell transition. Clear: go straight. Blocked: request an A* path to the target under raider walking rules (enemy faction, `RAIDER_CLIMB` / `RAIDER_DROP`, gates as `RaiderField.step_ok` sees them). Prefer giving `Pathfind.find` a faction parameter (default `PLAYER`, so units are unchanged) and a small raider def over writing a second A*. Searches go through a budget queue like `UnitPaths` (own tunables `RAIDER_PATH_FRAME_MS`, `RAIDER_PATH_MAX_NODES`); while a request waits, the raider follows the flow field, never stands still.
3. **Follow it.** Walk the waypoints with `RaiderMove.walk`. Re-plan only when: terrain or a gate changed, the existing stuck handling fires, or the path ends without reaching striking distance. Delete the `detour` timer and `RAIDER_DETOUR_TIME`.
4. Raiders with no target keep following the shared flow field exactly as now (it is already a shortest route and does not dither).
