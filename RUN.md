# How to run Creeper Ops

Run these from the project folder (`creeper fps td/`).

```
godot --path godot          # play the game
godot -e --path godot       # open the Godot editor
godot --path godot res://scenes/firing_range.tscn   # Firing Range (Tarkov-style combat test level)
```

From anywhere:

```
godot --path "/home/gregory-milligan/AI projects/creeper fps td/godot"
```

Handy keys in game: **F10** Controls (rebind keys), **F8** test recall, **F9** mute.
